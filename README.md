# JS Arrays
This is the thirteenth exercise I have completed as part of the web development master. It focuses on mastering array manipulation and iteration using the basic `for` loop in JavaScript.
Repository name: `js-arrays`

## 📝 Task
Starting from the provided codebase, complete all the required tasks inside each script file. Use the browser DevTools and `console.log()` to verify the results.

### 🌟 Bonus
Inside the source code, there are a few script files containing bonus tasks that can be completed after finishing the core exercises.

### ⚠️ Important Note
Do not use advanced array methods like `map()`, `filter()`, or `includes()` at this stage. All solutions must be achieved purely by using standard `for` loops to strengthen fundamental logical thinking.
